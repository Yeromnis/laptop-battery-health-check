This PowerShell script quickly generates a battery health report for your laptop. This information can be useful for you or if you're selling your device.
The release version is compiled using ps2exe.

Ce script en PowerShell produit rapidement un bilan de santé de la batterie de votre ordinateur portable. Cette information peut être utile pour vous ou pour revendre votre matériel.
La version release est compilée avec ps2exe.
